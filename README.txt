NOVA FRONTEND WEBSITE

Files:
- index.html: webpage structure
- style.css: design and responsive layout
- script.js: mobile menu and current year

How to run:
1. Extract the ZIP file.
2. Open the frontend_website folder.
3. Double-click index.html to open it in your browser.

No backend or database is required.
You can edit the text and colors in the HTML and CSS files.
The Google Fonts import requires an internet connection; the page still works with fallback fonts offline.
